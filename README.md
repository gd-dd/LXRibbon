# LX 飘带 v0.0.1

适用于 3ds Max 2026 的普通父子骨骼单链。全中文 Max 内窗口，白底嫩叶绿配色。

## 使用
1. 解压整个目录，保持三个业务文件在一起。
2. 在 Max 中选择“脚本 → 运行脚本”，打开 `打开飘带.ms`。
3. 选择根骨骼并点击“读取选中的骨骼链”。末端骨骼仅作为定位点。
4. 设置帧范围与参数，保存场景后点击“解算并烘焙”。使用 Max 撤销恢复。

重力按场景单位/秒²输入，厘米场景地球重力约 980，米场景约 9.8。惯性越大越保留世界空间运动；质量越大越不易受阻尼减速。长度影响系数为零时阻尼统一，增大后较长骨段保留更多运动，骨段几何长度保持不变。

## 限制
当前为固定长度摆链模型，不含布料面、碰撞、自碰撞或扭转解算。仅支持普通骨骼与普通旋转控制器，不支持分叉、CAT、Biped、IK、非均匀缩放或有位置动画的子骨骼。以开始帧为初始姿态，根骨骼位置动画驱动摆动；根旋转由解算覆盖，链节点位置与旋转一同烘焙。需要保留角色驱动旋转时，使用独立父级带动飘带根骨骼。

烘焙写入范围内每帧变换键，不删除范围外关键帧，但边界插值可能改变。请在场景副本中试用。支持 Max 2026（已在 2026.3 后台验证）。真实蒙皮场景与撤销交互仍需使用者验收。
